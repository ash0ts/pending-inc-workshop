# Start the workshop

The QR code now leads to the current gateway-free workshop.

1. Sign in to [Forge](https://forge.coreweave.com) and create a public teaching project you can write to.
2. [Open the Pending template](https://forge.coreweave.com/notebooks/Tm90ZWJvb2s6MTU3NzQ=/view). Choose **Copy to project**, select your project, and open your copy in Edit mode.
3. Initialize the notebook's cells once, then click **Check my project and restore saved work**. Confirm that the displayed project is yours.
4. Work through the code exercises. Only explicit run buttons start model calls. You use your own inference access and billing; the default adjustable allowance is $8, with notebook compute separate.

You do not need a facilitator token, renewed endpoint or workshop service. [Complete setup and laptop instructions](https://github.com/ash0ts/forge-workshop-kit).

The [earlier releases](https://github.com/ash0ts/pending-inc-workshop/releases) and their saved work remain available. Start a new notebook for the current workshop; updating this guide does not alter an existing attendee copy.
